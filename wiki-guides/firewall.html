Firewall

================

1. What is this?

A firewall is a network security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules. It acts as a barrier between a trusted network and an untrusted network, such as the internet.

2. What you need

  • AcreetionOS installed on your system
  • Root or sudo privileges
  • A firewall configuration file (optional)

3. Step-by-step

Install and enable the firewall
  1. Open a terminal and update the package list:
    2. sudo pacman -Syu
  2. Install the `firewalld` package:
    3. sudo pacman -S firewalld
  3. Enable and start the firewall service:
    4. sudo systemctl enable firewalld
sudo systemctl start firewalld
    Configure the firewall
    1. Open the firewall configuration file:
      2. sudo nano /etc/firewalld/firewalld.conf
    2. Add or modify rules as needed. For example, to allow incoming traffic on port 22 (SSH):
      3. sudo firewall-cmd --zone=public --add-port=22/tcp
    3. Reload the firewall rules:
      4. sudo firewall-cmd --reload
      Allow incoming traffic on a specific port
      1. Open the firewall configuration file:
        2. sudo nano /etc/firewalld/services.xml
      2. Add a new service definition:
        3. <service name="http">
  <port port="80" protocol="tcp"/>
</service>
      3. Reload the firewall rules:
        4. sudo firewall-cmd --reload

        4. Troubleshooting

        • Check the firewall status:
          • sudo firewall-cmd --state
        • Check the firewall rules:
          • sudo firewall-cmd --list-all
        • Disable the firewall:
          • sudo systemctl stop firewalld
        • Re-enable the firewall:
          • sudo systemctl start firewalld
