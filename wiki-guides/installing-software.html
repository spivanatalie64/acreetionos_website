Installing Software on AcreetionOS (Cinnamon Desktop)

1. What is this?

This guide teaches you how to install software on AcreetionOS, an Arch-based Linux distribution featuring the Cinnamon desktop environment. Whether you're a complete beginner or have some experience, these steps will help you add new programs to your system using both graphical (GUI) and terminal commands.

---

2. What You Need

Before starting, ensure you have:

  • **Root/sudo privileges** – Most software installations require administrative rights.
  • **Internet connection** – To download packages from repositories.
  • **A working AcreetionOS system** – Freshly installed or up-to-date.
  • **Optional but recommended**:
  • A text editor (e.g., `nano`, `vim`) for manual file management.
  • Terminal access (essential for advanced operations).

On AcreetionOS, you can manage packages via the built-in Software Manager (GUI) or directly through the pacman command-line tool.

---

3. Step-by-Step Installation Guide

Method A: Using the Software Manager (GUI) — Beginner Friendly

This method uses the graphical interface, making it easy for newcomers.

  1. **Open the Software Manager**
  2. Click the **Start menu** (or press `Alt + F4` then select "Software" if shortcut is set).
  3. Alternatively, search for "Software Manager" in the application launcher.
    1. **Browse or Search for the Application**
    2. In the main window, click **"Install"** at the top left.
    3. Type the name of the software you want (e.g., "Google Chrome", "VLC Media Player", "LibreOffice").
    4. Select the desired version and click **"Install"**.
      1. **Wait for Installation**
      2. The Software Manager will download and install the program automatically.
      3. Once complete, the app icon will appear in your Start menu.
        1. **Launch the Application**
        2. Find the newly installed app in the list or start menu.
        3. Double-click to open it and begin using.

          4. > Tip: For many popular apps, AcreetionOS has pre-configured versions available in the official repositories (community and extra groups), so no manual compilation is required.

          ---

          Method B: Using Terminal (Advanced) — Pacman Command Line

          This approach gives you more control and works even when the GUI is unavailable.

          Step 1: Update Your Package List
          sudo pacman -Syu

          This ensures all your system packages are up to date before installing anything new.

          Step 2: Search for the Software
          sudo pacman -Ss <software-name>

          Replace <software-name> with what you're looking for (e.g., chromium, vlc, libreoffice). This shows available versions and their sources.

          Step 3: Install the Software

          Once you find the correct package name (e.g., vlc), run:

          sudo pacman -S <package-name>

          For example:

          sudo pacman -S vlc
          Step 4: Verify Installation

          After installation completes, check that the program is available:

          which <app-name>  # e.g., which vlc

          Or simply try launching it from the terminal:

          vlc &

          4. Troubleshooting

          | Issue | Possible Cause | Solution |

          |-------|----------------|----------|

          | Package not found | Not in default repositories | Add a repository (e.g., pacman-mirrors) or compile from source. |

          | Installation fails with "permission denied" | Missing sudo/root privileges | Use sudo prefix before commands like pacman -S. |

          | App doesn't launch after installation | Missing dependencies | Run sudo pacman -Syu again to update all packages. |

          | Software crashes immediately | Incompatible version or missing libraries | Check the error
