WiFi

Connect to WiFi on AcreetionOS

1. What is this?

This guide will show you how to connect to a wireless network (WiFi) on your AcreetionOS computer. You can use either the easy graphical method or the advanced terminal method.

2. What you need

  • A working WiFi adapter (built-in or USB)
  • The name (SSID) and password of the WiFi network you want to join
  • An internet connection if you need to install additional software (rare)

3. Step-by-step (GUI Method)

Step 1: Turn on WiFi

  • Click the **network icon** in the bottom-right corner of your screen (it looks like a signal bar or a computer screen with waves).
  • If it says "WiFi Off", click it and select **Turn WiFi On**.

Step 2: Find your network

  • Click the **network icon** again to open the WiFi list.
  • Wait for a list of available networks to appear.

Step 3: Connect to a network

  • Find your network's name (SSID) in the list and click it.
  • A window will pop up asking for the password.
  • Type the WiFi password carefully (check "Show password" if you want to see what you're typing).
  • Click **Connect**.

Step 4: Verify connection

  • The network icon should now show a full signal.
  • Open a web browser and try visiting any website to confirm you're online.

4. Step-by-step (Advanced - Terminal Method)

If the GUI method doesn't work or you prefer using commands:

Step 1: Check if WiFi is enabled

nmcli radio wifi

If it says "enabled", you're good. If it says "disabled", enable it with:

nmcli radio wifi on

Step 2: Scan for networks

nmcli device wifi list

This will show all available networks around you.

Step 3: Connect to a network

Replace YOUR_SSID with your network name and YOUR_PASSWORD with the password:

nmcli device wifi connect YOUR_SSID password YOUR_PASSWORD

Step 4: Verify connection

nmcli connection show

You should see your network listed as connected.

5. Troubleshooting

Problem: WiFi won't turn on

  • **Solution**: Try restarting the NetworkManager service:
    •   sudo systemctl restart NetworkManager

Problem: Can't find any networks

  • **Solution**: Make sure your WiFi adapter is properly connected. Try:
    •   sudo rfkill unblock wifi

Problem: Wrong password

  • **Solution**: Double-check the password. WiFi passwords are case-sensitive. Try connecting again.

Problem: Connected but no internet

  • **Solution**: Try restarting your router, or check if other devices can connect to the same network.

Problem: WiFi icon missing from panel

  • **Solution**: Right-click the panel, select "Panel Settings" → "Applets", and make sure the "Network" applet is enabled.

Need more help?

If none of these steps work, you can ask for help on the AcreetionOS community forum or check the Arch Wiki for more advanced troubleshooting steps.
